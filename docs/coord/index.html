AuroraCoord · Settings

The panel links with the AuroraPAR / AuroraCoord panels of the same airport. Tower: the tower side. Radar: the radar side (also as an extra panel next to AuroraPAR). Monitor: sees the lights and who is online, cannot press anything. Panel code: the same code as on the other panels (empty: the open channel of the airport).

Buttons: colour and engraved text (the last one is reset)

Tip: add this page to the home screen (browser menu → Add to Home screen) to open it full screen like an app.
